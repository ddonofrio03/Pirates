# ⚾ Pittsburgh Pirates Live Scoreboard

Real-time Pirates game tracker powered by the **official MLB Stats API** — no API key required.

## Features
- Live score with inning-by-inning breakdown
- Current pitcher and batter stats
- Balls, strikes, outs and base runners
- Full batting and pitching box scores
- Next game + starting pitchers on off days
- Auto-refreshes every 30 seconds

**Live app:** https://ddonofrio03.github.io/Pirates/
